# 系统日志

当前版本提供「常规日志」，用于查看 MoriBot 运行情况和普通业务接口调用。

## 1. 日志来源

| 来源 | `source` | 内容 |
| --- | --- | --- |
| 应用 | `app` | 启动/停止、模型加载、定时检测、插件、平台、异常等 loguru 运行日志 |
| 接口 | `http` | `/api/v1/*` 普通业务接口的请求记录 |

接口日志格式示例：

```text
GET /api/v1/providers -> 200 (27 ms) actor=user:admin ip=127.0.0.1
```

记录字段：

- HTTP 方法
- 请求路径（不记录查询字符串）
- 响应状态码
- 耗时
- 操作者：后台用户、MoriMobile 设备或匿名
- 客户端 IP

不会记录请求体、响应体、API Key 或密码。日志页面自身和健康检查不会写入接口日志，避免自增噪声。

## 2. 日志页面

左侧「系统日志」页面支持：

- 按最低级别过滤：DEBUG / INFO / WARNING / ERROR
- 按来源过滤：应用 / 接口
- 按关键字搜索
- 自动刷新（每 5 秒，可关闭）
- 手动刷新
- 下载当前 `moribot.log` 文件

页面展示最近 2000 条内存日志，最新的在最上面。自动刷新不会触发额外的接口日志。

## 3. 持久化

- 运行日志写入 `data/logs/moribot.log`。
- 文件按 10 MB 轮转，保留 14 天。
- 「下载日志」下载当前日志文件。
- 日志文件不包含在数据备份中，便于控制备份体积。

## 4. API

```http
GET /api/v1/system/logs?level=ERROR&source=http&q=providers&limit=300
GET /api/v1/system/logs/download
```

查询参数：

| 参数 | 说明 |
| --- | --- |
| `level` | 最低级别；`ERROR` 只返回 ERROR/CRITICAL |
| `source` | `app` 或 `http` |
| `q` | 消息关键字，不区分大小写 |
| `limit` | 返回条数，默认 300，最大 1000 |

## 5. 当前限制

- 页面只保留最近 2000 条内存日志，更早内容请下载日志文件。
- 暂未提供 WebSocket/SSE 实时推送；页面通过轮询刷新。
- 暂未单独拆分错误日志、审计日志等频道，后续可在常规日志基础上扩展。
